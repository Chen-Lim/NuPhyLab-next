# 退出与窗口大小 / Quitting and window size

键盘未连接时，NuPhy Lab 会保留完整的休眠设置备份，待原键盘再次连接后继续处理。正常保留的备份不会再因为当前没有设备连接而触发“暂时未能完成”的误提示。真正无法恢复或记录损坏时，软件仍会提示处理。

When the keyboard is disconnected, NuPhy Lab retains its sleep-settings backup until the original keyboard reconnects. A valid retained backup no longer triggers an incomplete-recovery warning merely because the device is absent. A damaged record or an actual recovery failure still requires attention.

主窗口启动时采用适中的默认大小，通常为 1080 × 720 内容点，并适配较小屏幕。正常保存的小窗口尺寸保留；过大或越界的旧窗口会回到当前显示器上的合理位置。使用中仍可自由调整或放大窗口。

The main window opens at a moderate default size, normally 1080 × 720 content points, adjusted for smaller screens. Normal saved window sizes are retained; oversized or off-screen windows return to a suitable position on the current display. You can still resize or maximize the window while using the app.
