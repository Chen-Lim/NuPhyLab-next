# 现有功能与本次交付范围

本说明依据 Chord 当前工作树阅读整理，日期为 2026-11-04。原项目的本机 0.9.5（28）和官网 0.9.4（27）是已有版本记录；本次没有安装、升级或发布它们。本包用于 Lab 二次接入，不能作为 Lab 已上线此功能的证明。

## 一次交互如何进行

1. 用户按住设置的键盘键或标准鼠标侧键，选择屏幕上的文字、对象或一块区域。
2. 用户可以同时说“翻译成英文”“总结一下”“解释这里的意思”等要求。语音在本机系统语音服务中识别为文字，不把音频交给模型 API。
3. 松开后，等待当前选区读取／截图和语音结束。口述要求优先；没有口述时按明确配置的默认动作执行，没有默认动作则等待用户选动作或输入问题。
4. 需要 AI 的动作将本次材料和要求发给所选服务，逐步显示答案。流中断、截断、拒绝或报错都不能把半截文字标为完成。
5. 用户阅读或复制最终答案。Esc、关闭、暂停、安全输入或权限失效会取消当前工作；新框选建立新会话，旧结果不能覆盖它。

语音录音或识别失败时，不会把半截口述自动发送，也不会直接执行默认动作；保留当前选区等待用户明确选择动作或输入修正后的问题。正常结束但没有说话，仍可按用户配置的默认动作处理。

Lab 负责按钮、浮窗、选区边框、文本输入和结果样式。交付代码保留上述流程约束，不要求沿用 Chord 的视觉设计。

## 动作与数据路径

| 动作 | 用途 | 本包处理方式 |
| --- | --- | --- |
| 翻译 | 翻译选中文字，保留意思及段落 | 目标语言由用户设置；有 OCR／AX 文字时仅发送文字，无文字时需视觉模型 |
| 总结 | 提炼内容要点 | 有文字时发送文字；只有图片时发送图片，要求模型具备图片输入能力 |
| 改写 | 调整表达与可读性 | 默认保持原意；仅生成结果文字，不改写原应用内容 |
| 解释 | 解释概念、句子、图表或界面 | 固定“解释”动作优先使用已识别文字；需要结合画面关系时使用自定义看图提问 |
| 提取文字 | 从选区获得文字 | 使用 Accessibility 或本机 Vision OCR，直接返回本地结果，不读取 API key 或发网络请求 |
| 自由提问 | 如“这张图说明什么”“这段代码哪里有问题” | 发送本次材料与口述／输入的问题；所选区域有截图时保留该图片，不静默丢弃 |

固定动作中的“文字优先”可以降低截图上传和模型费用，但 OCR 不能保留所有图表关系。纯视觉理解应走自定义提问；图片能力未确认时返回明确错误，不能悄悄变成仅文字请求。

没有自动替换原文、执行代码、点击网页或操作电脑。复制按钮由 Lab 使用最终 `result` 实现；`preview` 只表示尚未完成的流式预览。包内没有自动复制到剪贴板的副作用。

## 内容从哪里来

- **选中的文字**：使用 macOS Accessibility 的选区信息，不模拟 Command-C、不读取用户剪贴板，也不扫描整篇文档。
- **明确点中的对象**：读取该对象公开的有限文字／名称；无法读取时提示重新选取。不会为失败的文字读取自动截图。
- **框选区域**：使用 ScreenCaptureKit 取得单帧截图，再用 Vision 本地识字。没有持续录屏；不捕获系统音频。区域至少 8 × 8 点且位于同一显示器，像素尺寸和总像素数均有限制。
- **语音要求**：只在用户主动开始且选择使用语音时采集麦克风。系统本地语言模型不可用时如实失败；没有悄悄切到云端语音。OCR 语言与语音 locale 可由 Lab 按用户设置传入。

发送图片时，HostExample 为网络生成独立的小图副本，最大边长 2048、最多 3 MiB；会话内原始像素不被替换。每次最多一张图，不写入文件或自动保存到相册。

Accessibility 和安全输入检查能拦住可识别的密码／受保护控件，但不能识别任意图片中的敏感内容。Lab 应准确展示当前目标区域和服务，让用户主动决定选择与发送。

## 本次新增的模型适配

原 Chord AI 配置主要是 OpenAI、DeepSeek、阿里云百炼和自定义服务，协议为 Responses 与 Chat Completions。本次交付的 AIKit 扩展到：

**OpenAI、Anthropic Claude、Google Gemini、OpenRouter、Groq、Mistral、xAI、DeepSeek、Qwen 中国、Qwen 国际，加自定义端点。**

这是 10 个服务／区域预设，不是 10 个固定模型。模型 ID 默认留空，需从账号可用目录选择或手填；图片能力需按具体模型确认。Anthropic 使用原生 Messages；Gemini 使用其官方 OpenAI 兼容接口。Qwen 国内和国际分别配置端点与密钥，模型目录本次仅手填。详细差异、官方资料和账号注意事项见 [API 调研](API调研与接入建议.md)。

这些新适配只在本交接包实现，没有回写到当前 Chord 应用或发布为新版本。

## 明确排除的内容

不交付“保存起来，最后一起提问”：没有跨次材料积累、收集列表、收集键、整组请求、整组追问或收集历史。不包含 A/B 多对象工作流，也不提供截图存档或图文备注编辑器。

会话中暂存一份选区，只为等待用户选择本次动作／展示本次结果；关闭、取消或新手势会清掉它。它不是可恢复的材料保存功能。一次请求结束后继续问新问题需重新开始一次选取，本包不维护聊天历史。

## 需要 Lab 完成的部分

Lab 接入工程依赖、复用自己的输入路由、设计 UI、设置服务和模型、保存 Keychain、配置权限说明、对接生命周期通知，并用目标账号和实体设备完成验收。本次已经提供相关底层源码、无 UI 接线示例及本地验证记录，尚未接入或修改 NuPhyLab。
